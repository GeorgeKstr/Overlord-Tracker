# Vision

## Modular SaaS Control Plane

An internal developer platform designed to be the single source of truth for managing projects, services, APIs, and deployments across the organization.

### Goals

- Provide a unified dashboard for all generated projects and services
- Enable structured ticket tracking with full hierarchy (tickets → subtickets)
- Act as a service registry with live health monitoring
- Ingest and visualize API metadata from all registered services
- Serve as the operational backbone for the software delivery lifecycle

### Non-Goals (MVP)

- This is NOT a low-code or drag-and-drop platform
- No Kubernetes or advanced orchestration in v1
- No billing, marketplace, or AI generation in v1
- No realtime collaboration in v1

### Target Users

Internal engineering teams who need:
- Visibility across all their services and APIs
- A structured way to manage work (projects → tickets)
- A service registry with health status
- API documentation aggregated in one place
