# Roadmap

## MVP (Current)

- [x] Monorepo structure
- [x] Docker Compose
- [x] NestJS API with modular architecture
- [x] Next.js dashboard with App Router
- [x] Prisma schema (User, Project, Ticket, Service, etc.)
- [x] Google OAuth via Auth.js
- [x] Projects CRUD
- [x] Tickets CRUD with subtickets
- [x] Comments and Labels
- [x] Service registry
- [x] API ingestion endpoint
- [x] Health dashboard
- [x] OpenAPI docs (Swagger)

## Phase 2

- [ ] GitHub repository integration (link repos to projects)
- [ ] BullMQ job queues for async processing
- [ ] Advanced ticket filtering and search
- [ ] Real-time updates via Server-Sent Events
- [ ] Role-based access control (RBAC)
- [ ] Deployment tracking (link deployments to services)
- [ ] API diff detection (detect breaking changes)

## Phase 3

- [ ] Multi-tenant support
- [ ] Kubernetes deployment manifests
- [ ] Slack / webhook notifications
- [ ] Advanced analytics and reporting
- [ ] CLI tool for project registration
